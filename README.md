# BUS BUDDIES — ぎゅうぎゅう駐車場

いろいろな向きに詰まった車を、進路の空いた順に駐車場から出すブラウザ用パズルです。
真上から見た、上下左右が分かる車と、色別の乗客・のりばを組み合わせています。

[ブラウザで遊ぶ](https://shousui-works.github.io/bus-buddies/)

## 開発

Node.js 20 以上を使います。追加パッケージのインストールは不要です。

~~~sh
npm run dev
~~~

http://127.0.0.1:5173 をブラウザで開きます。

~~~sh
npm test
~~~

## 遊び方

- 車は屋根の矢印の方向へまっすぐ進みます。別の車が進路をふさいでいると出せません。
- 進路が空いた車を選ぶと、駐車場から脱出して上ののりばへ移動します。
- 乗客は列のどこにいても、同じ色の車へ自動で乗ります。乗らなかった人の順番はそのままです。色には見分けるためのマークも付いています。
- 小さな車の定員は4人、長いバスは6人です。満員になると自動で出発します。
- のりばは最初5枠。「待機枠 +1」で無料で2枠まで追加できます。
- 「ヒント」はクリアにつながる車を光らせます。「1手戻す」で操作を取り消せます。
- 「シャッフル」は同じステージを新しい配置と乗客の列に入れ替えます。これも1手戻せます。
- 20台・24台・28台・32台・36台の5ステージ。クリア状況はブラウザに保存されます。

各配置は、逆順で車を配置する方法で、車がすべて脱出できる手順を確保します。
乗客は色ごとの定員と同じ人数を用意し、先頭以外からの乗車・全員の乗車・定員の整合性をテストで確認しています。
シャッフル後も同じ条件を満たします。

## 構成

- public/index.html — 街・乗客・のりば・駐車場・ダイアログ
- public/style.css — スマホ向けのゲーム画面とアニメーション
- public/app.mjs — 操作、脱出・乗車アニメーション、音、保存
- public/engine.mjs — 4方向の進路判定、配置生成、乗車処理、解法探索
- public/renderer.mjs — 元の図形から描く真上視点の車と駐車場のSVG
- tests/engine.test.mjs — 交差する進路、配置とシャッフルの解法、乗客数、定員、列の途中からの乗車のテスト
- scripts/serve.mjs — ローカル開発用サーバー

フレームワーク・ビルド処理・画像アセットに依存しない静的サイトです。
public/ をWebルートとして配信できます。Google Fonts に接続できない場合はシステムフォントを使います。
以前の縦一列型パズルのクリア状況は、新しいルールのステージとは分けて保存します。

## 公開

main へのpush時に .github/workflows/deploy.yml がテストを実行し、成功した場合だけ public/ をGitHub Pagesへ公開します。
