# BUS BUDDIES — バスっと、出発！

乗客と同じ色のバスを出して、全員を目的地へ送り出すブラウザ用パズルゲームです。PC・スマートフォンに対応しています。

## 開発

Node.js 20 以上を使います。追加パッケージのインストールは不要です。

```sh
npm run dev
```

表示された http://127.0.0.1:5173 をブラウザで開きます。

```sh
npm test
```

全5ステージの解法、ヒント、乗客数の整合性、移動制限、失敗判定を検証します。

## 遊び方

- 駐車場の前が空いているバスを選ぶと、3枠ののりばへ移動します。
- 乗客は列の先頭から、同じ色・マークのバスに自動で乗ります。
- 3人で満員になると出発し、のりばが空きます。
- 3枠とも埋まり、先頭の乗客が乗れなくなると失敗です。
- 「1手戻す」「ヒント」「やり直す」で何度でも試せます。
- ステージのクリア状況はブラウザに保存されます。

## 構成

- `public/index.html` — 画面とダイアログ
- `public/style.css` — レスポンシブ表示とバスの描画
- `public/app.mjs` — 操作、アニメーション、音、保存
- `public/engine.mjs` — ステージ生成、ルール、解法探索
- `tests/engine.test.mjs` — ゲームルールのテスト
- `scripts/serve.mjs` — ローカル開発用サーバー

フレームワークやビルド処理に依存しない静的サイトです。`public/` をWebルートとして配信できます。フォントは Google Fonts から読み込み、接続できない場合はシステムフォントを使います。
